# Assignment Overview

---

### 1. `TypeValidationAssignment.md`

* **What it is:** An exercise focused on Python's type hinting system.
* **What you will do:** Look at 20 different variable declarations and type hints (using basic types, lists, dictionaries, sets, and tuples). Without running Mypy or Python, your task is to **guess which ones are correct and which ones have type mismatches/errors**.

### 2. `RoutingAssignment.md`

* **What it is:** A two-part practical challenge on FastAPI routing, path parameters, priority order, and the `:path` converter.
* **What you will do:**
* **Part 1 (Prediction Quiz):** Analyze a given FastAPI app with stacked routes and predict which route function triggers for 20 different incoming request URLs (and what text it returns).
* **Part 2 (Code-Writing Challenge):** Read specific client requirements and **write the exact FastAPI code** (decorators and functions) to handle those routes properly.
