# Project 2: E-Commerce Shopping Cart System

## 1. Real-World Scenario & Theoretical Foundation

When shopping on platforms like Amazon or Shopify, customers require a temporary digital container (a shopping cart) to hold items they intend to purchase. The system must support dynamic addition, modification, and removal of products while maintaining a key-value mapping (`{item_name: price}`) and computing final checkout totals inclusive of sales tax.

---

## 2. Core OOP Concepts & Pillars Used

* **Encapsulation:** Bundling user session data (`user_id`, `items`) and cart behaviors (`add_item`, `remove_item`, `update_item`, `calculate_total`) inside the `ShoppingCart` class.
* **Dictionary State Mapping:** Using Python dictionaries for $O(1)$ item lookup, rapid price updates, and effortless removals.
* **CRUD Architecture:**
* **Create:** Add items to the shopping cart.
* **Read:** View current items in the cart and review subtotals.
* **Update:** Modify existing item prices or update quantities.
* **Delete:** Remove specific items or clear the entire cart.



---

## 3. Complete Python Source Code (CLI & Core Logic with Full CRUD)

```python
class ShoppingCart:
    def __init__(self, user_id):
        self.user_id = user_id
        self.items = {}  # Format: {item_name: price}

    def add_item(self, item_name, price):
        if price < 0:
            print("Error: Price cannot be negative.")
            return
        self.items[item_name] = price
        print(f"Success: Added '{item_name}' (${price:.2f}) to cart for user {self.user_id}.")

    def update_item_price(self, item_name, new_price):
        if item_name in self.items:
            if new_price < 0:
                print("Error: Price cannot be negative.")
                return
            self.items[item_name] = new_price
            print(f"Success: Updated price of '{item_name}' to ${new_price:.2f}.")
        else:
            print(f"Error: '{item_name}' is not in your cart.")

    def remove_item(self, item_name):
        if item_name in self.items:
            del self.items[item_name]
            print(f"Success: Removed '{item_name}' from cart.")
        else:
            print(f"Error: '{item_name}' was not found in your cart.")

    def view_cart(self):
        if not self.items:
            print("\nYour shopping cart is currently empty.")
            return
        print("\n" + "="*40)
        print(f"       SHOPPING CART (User: {self.user_id})")
        print("="*40)
        for name, price in self.items.items():
            print(f" - {name:<22} : ${price:>6.2f}")
        print("="*40)

    def calculate_total(self, tax_rate=0.08):
        subtotal = sum(self.items.values())
        tax_amount = subtotal * tax_rate
        total = subtotal + tax_amount
        return subtotal, tax_amount, round(total, 2)

def main():
    user_id = input("Enter User ID / Name for Shopping Cart: ").strip()
    cart = ShoppingCart(user_id)

    while True:
        print("\n--- E-COMMERCE SHOPPING CART MENU (CRUD) ---")
        print("1. Add Item to Cart (Create)")
        print("2. View Cart Items (Read)")
        print("3. Update Item Price (Update)")
        print("4. Remove Item from Cart (Delete)")
        print("5. Checkout & Calculate Total")
        print("6. Exit")

        choice = input("Enter your choice (1-6): ").strip()

        if choice == '1':
            print("\n--- Add Item ---")
            item = input("Enter product name: ").strip()
            try:
                price = float(input("Enter product price ($): "))
                cart.add_item(item, price)
            except ValueError:
                print("Invalid price format. Please enter a valid number.")

        elif choice == '2':
            cart.view_cart()

        elif choice == '3':
            print("\n--- Update Item Price ---")
            item = input("Enter product name to update: ").strip()
            try:
                new_price = float(input("Enter new price ($): "))
                cart.update_item_price(item, new_price)
            except ValueError:
                print("Invalid price format.")

        elif choice == '4':
            print("\n--- Remove Item ---")
            item = input("Enter product name to remove: ").strip()
            cart.remove_item(item)

        elif choice == '5':
            sub, tax, total = cart.calculate_total(tax_rate=0.08)
            cart.view_cart()
            print(f"Subtotal       : ${sub:.2f}")
            print(f"Sales Tax (8%) : ${tax:.2f}")
            print(f"Final Total    : ${total:.2f}")
            print("Thank you for shopping with us!")

        elif choice == '6':
            print("Exiting shopping cart. Goodbye!")
            break
        else:
            print("Invalid option. Please choose between 1 and 6.")

if __name__ == "__main__":
    main()

```
