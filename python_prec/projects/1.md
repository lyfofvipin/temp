# Project 1: Bank Account Management System

## 1. Real-World Scenario & Theoretical Foundation

In modern banking software, thousands of customer accounts are managed simultaneously. Instead of writing isolated variables for each customer (`name1`, `balance1`, etc.), Object-Oriented Programming (OOP) allows us to encapsulate all related attributes and behaviors into a single blueprint called a **Class**.

Each individual customer account is an **Object** (an instance of the `BankAccount` class). All account objects are stored within a central data structure (a Python list), enabling full **CRUD (Create, Read, Update, Delete)** operations.

---

## 2. Core OOP Concepts & Pillars Used

* **Encapsulation:** Bundling customer data (`name`, `mobile`, `age`, `dob`, `balance`) and methods (`deposit`, `withdraw`, `update_info`) together inside the `BankAccount` class.
* **State Management:** Tracking dynamic attributes (`balance`) that change over time in response to user transactions.
* **CRUD Architecture:**
* **Create:** Open a new bank account.
* **Read:** Search for an account and view details/balance.
* **Update:** Deposit money, withdraw money, or update customer profile details.
* **Delete:** Close/remove an existing bank account from the system.



---

## 3. Complete Python Source Code (CLI & Core Logic with Full CRUD)

```python
class BankAccount:
    def __init__(self, customer_name, mobile_number, age, date_of_birth, initial_balance=0.0):
        self.customer_name = customer_name
        self.mobile_number = mobile_number
        self.age = age
        self.date_of_birth = date_of_birth
        self.balance = float(initial_balance)

    def deposit(self, amount):
        if amount > 0:
            self.balance += amount
            print(f"Successfully deposited ${amount:.2f}.")
            self.display_balance()
        else:
            print("Error: Deposit amount must be greater than zero.")

    def withdraw(self, amount):
        if amount <= 0:
            print("Error: Withdrawal amount must be greater than zero.")
        elif amount <= self.balance:
            self.balance -= amount
            print(f"Successfully withdrew ${amount:.2f}.")
            self.display_balance()
        else:
            print(f"Insufficient funds! Current balance is ${self.balance:.2f}.")

    def update_details(self, name, age, dob):
        self.customer_name = name
        self.age = age
        self.date_of_birth = dob
        print("Account details updated successfully.")

    def display_balance(self):
        print(f"Current Account Balance: ${self.balance:.2f}")

    def display_account_info(self):
        print("\n" + "="*40)
        print("         BANK ACCOUNT DETAILS")
        print("="*40)
        print(f"Customer Name : {self.customer_name}")
        print(f"Mobile Number : {self.mobile_number}")
        print(f"Age           : {self.age}")
        print(f"Date of Birth : {self.date_of_birth}")
        print(f"Balance       : ${self.balance:.2f}")
        print("="*40)

def search_account(accounts_list, mobile):
    for acc in accounts_list:
        if acc.mobile_number == mobile:
            return acc
    return None

def main():
    accounts = []
    
    while True:
        print("\n--- BANK MANAGEMENT SYSTEM (CRUD) ---")
        print("1. Create New Account (Create)")
        print("2. Check Account Details (Read)")
        print("3. Deposit Money (Update)")
        print("4. Withdraw Money (Update)")
        print("5. Update Customer Profile (Update)")
        print("6. Close/Delete Account (Delete)")
        print("7. Exit")

        choice = input("Enter your choice (1-7): ").strip()
        
        if choice == '1':
            print("\n--- Create New Account ---")
            mobile = input("Enter Mobile Number: ").strip()
            if search_account(accounts, mobile):
                print("Error: An account with this mobile number already exists!")
                continue
            name = input("Enter Customer Name: ").strip()
            try:
                age = int(input("Enter Age: "))
                dob = input("Enter Date of Birth (DD-MM-YYYY): ").strip()
                balance = float(input("Enter Initial Deposit Amount: "))
            except ValueError:
                print("Invalid input format for age or balance.")
                continue
                
            new_acc = BankAccount(name, mobile, age, dob, balance)
            accounts.append(new_acc)
            print(f"Success! Account created for {name}.")
            
        elif choice == '2':
            print("\n--- Check Account Details ---")
            mobile = input("Enter Mobile Number to search: ").strip()
            acc = search_account(accounts, mobile)
            if acc:
                acc.display_account_info()
            else:
                print("No account found with this mobile number.")
                
        elif choice == '3':
            print("\n--- Deposit Money ---")
            mobile = input("Enter Mobile Number: ").strip()
            acc = search_account(accounts, mobile)
            if acc:
                try:
                    amt = float(input("Enter amount to deposit: "))
                    acc.deposit(amt)
                except ValueError:
                    print("Invalid amount entered.")
            else:
                print("No account found with this mobile number.")
                
        elif choice == '4':
            print("\n--- Withdraw Money ---")
            mobile = input("Enter Mobile Number: ").strip()
            acc = search_account(accounts, mobile)
            if acc:
                try:
                    amt = float(input("Enter amount to withdraw: "))
                    acc.withdraw(amt)
                except ValueError:
                    print("Invalid amount entered.")
            else:
                print("No account found with this mobile number.")

        elif choice == '5':
            print("\n--- Update Customer Profile ---")
            mobile = input("Enter Mobile Number: ").strip()
            acc = search_account(accounts, mobile)
            if acc:
                new_name = input("Enter new name: ").strip()
                try:
                    new_age = int(input("Enter new age: "))
                    new_dob = input("Enter new DOB (DD-MM-YYYY): ").strip()
                    acc.update_details(new_name, new_age, new_dob)
                except ValueError:
                    print("Invalid age entered.")
            else:
                print("No account found with this mobile number.")

        elif choice == '6':
            print("\n--- Close/Delete Account ---")
            mobile = input("Enter Mobile Number to delete: ").strip()
            acc = search_account(accounts, mobile)
            if acc:
                accounts.remove(acc)
                print(f"Account associated with mobile {mobile} has been closed/deleted.")
            else:
                print("No account found with this mobile number.")
                
        elif choice == '7':
            print("Thank you for using our banking system. Goodbye!")
            break
        else:
            print("Invalid choice! Please select between 1 and 7.")

main()
```
