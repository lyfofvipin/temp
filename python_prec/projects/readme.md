## 💡 Key Technical Highlights

1. **Object-Oriented Architecture:** Every application models real-world entities as distinct Python classes with tightly encapsulated data and behaviors.
2. **Dual-Interface Flexibility:** Projects 5 through 8 feature both text-based **Command Line Interfaces (CLI)** and graphical **Tkinter GUI** applications.
3. **Advanced Magic (Dunder) Methods:** Projects 9 and 10 leverage operator overloading (`__add__`, `__sub__`, `__gt__`, `__str__`, `__len__`) to make object interaction intuitive and Pythonic.
4. **Local Data Persistence:** Implementations use built-in Python libraries (`json`) to save and load state locally without requiring external database engines.
