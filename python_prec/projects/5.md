# Project 5: Library Book Management System

## 1. Real-World Scenario & Theoretical Foundation

Library management software is essential for tracking physical and digital book inventories, patron borrowing histories, and book availability. Each book is modeled as an instance of the `Book` class, encapsulating its metadata and loan status within a centralized catalog system.

---

## 2. Core OOP Concepts & Pillars Used

* **Encapsulation:** Bundling book attributes (`title`, `author`, `isbn`, `is_borrowed`, `borrower`) and behaviors (`borrow_book`, `return_book`, `update_book`) inside the `Book` class.
* **Boolean State Flags:** Managing `is_borrowed` to track whether a book is currently on the shelf or checked out.
* **CRUD Architecture:**
* **Create:** Add new books to the library catalog inventory.
* **Read:** Search for books and view borrowing statuses.
* **Update:** Check out books to patrons, return books, or update book metadata.
* **Delete:** Remove outdated or damaged books from the library inventory.



---

## 3. Complete Python Source Code (CLI & Core Logic with Full CRUD)

```python
class Book:
    def __init__(self, title, author, isbn):
        self.title = title
        self.author = author
        self.isbn = str(isbn)
        self.is_borrowed = False
        self.borrower = None

    def borrow_book(self, patron_name):
        if not self.is_borrowed:
            self.is_borrowed = True
            self.borrower = patron_name
            print(f"Success: '{self.title}' has been checked out to {patron_name}.")
        else:
            print(f"Error: '{self.title}' is currently checked out by {self.borrower}!")

    def return_book(self):
        if self.is_borrowed:
            print(f"Success: '{self.title}' returned by {self.borrower}. Book is back on the shelf.")
            self.is_borrowed = False
            self.borrower = None
        else:
            print(f"Error: '{self.title}' was not checked out.")

    def update_book(self, new_title, new_author):
        self.title = new_title
        self.author = new_author
        print(f"Success: Book details for ISBN {self.isbn} updated.")

    def display_status(self):
        status = f"Checked out to {self.borrower}" if self.is_borrowed else "Available on shelf"
        print(f"ISBN: {self.isbn} | Title: '{self.title}' by {self.author} | Status: {status}")

def find_book(catalog, isbn):
    for book in catalog:
        if book.isbn == isbn:
            return book
    return None

def main():
    catalog = [
        Book("The Great Gatsby", "F. Scott Fitzgerald", "9780743273565"),
        Book("To Kill a Mockingbird", "Harper Lee", "9780061120084"),
        Book("1984", "George Orwell", "9780451524935")
    ]

    while True:
        print("\n--- LIBRARY MANAGEMENT SYSTEM (CRUD) ---")
        print("1. Add New Book to Catalog (Create)")
        print("2. View Library Catalog (Read)")
        print("3. Check Out Book to Patron (Update)")
        print("4. Return Book (Update)")
        print("5. Delete Book from Catalog (Delete)")
        print("6. Exit")

        choice = input("Enter your choice (1-6): ").strip()

        if choice == '1':
            print("\n--- Add New Book ---")
            isbn = input("Enter ISBN: ").strip()
            if find_book(catalog, isbn):
                print("Error: A book with this ISBN already exists!")
                continue
            title = input("Enter Book Title: ").strip()
            author = input("Enter Author Name: ").strip()
            
            catalog.append(Book(title, author, isbn))
            print(f"Success! '{title}' added to the library catalog.")

        elif choice == '2':
            print("\n--- Library Catalog Inventory ---")
            for book in catalog:
                book.display_status()

        elif choice == '3':
            print("\n--- Check Out Book ---")
            isbn = input("Enter ISBN of book to borrow: ").strip()
            book = find_book(catalog, isbn)
            if book:
                patron = input("Enter Patron Name: ").strip()
                book.borrow_book(patron)
            else:
                print("Error: Book with this ISBN not found.")

        elif choice == '4':
            print("\n--- Return Book ---")
            isbn = input("Enter ISBN of book to return: ").strip()
            book = find_book(catalog, isbn)
            if book:
                book.return_book()
            else:
                print("Error: Book with this ISBN not found.")

        elif choice == '5':
            print("\n--- Delete Book ---")
            isbn = input("Enter ISBN of book to delete: ").strip()
            book = find_book(catalog, isbn)
            if book:
                if book.is_borrowed:
                    print("Error: Cannot delete a book that is currently checked out!")
                else:
                    catalog.remove(book)
                    print(f"Book with ISBN {isbn} removed from catalog.")
            else:
                print("Error: Book not found.")

        elif choice == '6':
            print("Exiting Library Management System. Goodbye!")
            break
        else:
            print("Invalid option. Please choose between 1 and 6.")

main()
```
